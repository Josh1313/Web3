Workflow

The framework is organized into six distinct functional layers that carry an audit from scope ingestion to verified exploit output. This is the part prospects need to understand: the value is not just automation, but structured progression from raw target to confirmed evidence.

Six-Layer Execution Map

Input Layer

Acts as the gateway for scope definition, accepting deployed contract addresses, GitHub repository URLs, and bug bounty program definitions.

Gateway to the pipeline

Collection Layer

Creates the target profile with verified Solidity source, ABI definitions, dependency trees, and protocol fingerprints.

Target intelligence

Analysis Layer

Executes six static analysis tools in parallel alongside mathematical checks and formal verification engines.

Parallel detection suite

Validation Layer

Filters and enriches raw findings through semantic deduplication and the anti-hallucination stack to isolate high-confidence signals.

Detective system

Exploitation Layer

Converts validated findings into executable proof-of-concept contracts using protocol-aware scaffold generation and multi-turn reasoning.

Attacker system

Output Layer

Classifies findings, stores results, and grows the historical knowledge base that makes later reviews sharper.

Persistent output layer
